# ♟️ Grandmaster AI – Chess Move Validator

## About the Project

Grandmaster AI is a chess application designed to make chess playing smarter and more interactive. It validates chess moves according to standard chess rules, identifies illegal moves and helps players understand valid moves. The application aims to provide a smooth chess experience with intelligent move analysis.

## Key Features

- **Interactive Chessboard** – Provides a board for playing chess.
- **Move Validation** – Checks whether a move is legal or illegal.
- **Illegal Move Detection** – Prevents invalid chess moves.
- **Piece Movement Rules** – Validates movements of all chess pieces.
- **Check Detection** – Identifies when a king is under attack.
- **Checkmate Detection** – Detects checkmate positions.
- **Move Navigation** – Allows players to go back and restart moves.
- **Game Status** – Displays the current game condition.

## Project Objective
The main objective of Grandmaster AI is to provide an interactive chess platform that validates moves, prevents rule violations and helps players develop a better understanding of chess.
